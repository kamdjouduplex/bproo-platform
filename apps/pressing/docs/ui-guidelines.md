# UI Guidelines (Based on Provided Design)

## Layout
- Top application bar with brand on the left.
- Primary navigation tabs in the top bar.
- Right side: language selector, notifications, user menu.
- Secondary toolbar for module context and quick actions.

## Content Areas
- Filter/search card aligned to the left.
- Detail panel tabs aligned to the right (when applicable).
- Data table with compact rows, status badges, and action icons.
- Pagination and export controls at the table header.

## Visual Language
- Clean light theme with high-contrast text.
- Primary accent: teal/green family.
- Subtle borders for cards and tables.
- Consistent input sizing and spacing.

## Responsiveness
- Desktop-first.
- Tablet: keep table, collapse filters into a drawer.
- Mobile: limit to core flows (sales, quick reporting).
