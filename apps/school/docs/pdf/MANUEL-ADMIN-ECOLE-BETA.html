1. Ce que vous allez tester

Bproo School digitalise le cycle de vie d’une école : élèves, inscriptions, scolarité, cartes, notes et bulletins.

Idées à retenir :

  • L’élève est créé une seule fois (profil permanent).
  • L’inscription se refait chaque année académique (classe / section).
  • Un profil incomplet n’empêche pas d’inscrire : un pourcentage de complétion indique ce qui manque.
  • Les classes, matières et enseignants se réutilisent d’une année à l’autre (pas de doublons).
Hors scope bêta : emplois du temps et présences élèves. Les SMS / e-mails automatiques peuvent être journalisés « ignorés » s’ils ne sont pas configurés — ce n’est pas un bug.

2. Connexion et premiers pas

2.1 Adresse

  1. Ouvrez un navigateur (Chrome, Edge ou Firefox).
  2. Allez sur : https://school.afroinov.com/app/login?tenant=VOTRE_CODE
  3. Remplacez VOTRE_CODE par le code de l’école (fourni à la création, pour votre cas: school).
Sans le paramètre ?tenant=..., l’application ne sait pas quelle école ouvrir. Conservez ce lien dans vos favoris.

2.2 Identifiants

Utilisez le compte administrateur créé pour votre école (e-mail + mot de passe transmis à l’ouverture).

Si un jeu de démo a été chargé, comptes types :

RôleE-mailMot de passe
Directeur (recommandé pour ce manuel)directeur.demo@school.testDirecteur#2025
Enseignantenseignant.demo@school.testEnseignant#2025
Caissiercaissier.demo@school.testCaissier#2025
Changez ces mots de passe dès que possible si vous n’êtes plus en démo interne.

2.3 Après connexion

Vous arrivez sur le tableau de bord : nombre d’élèves, inscriptions de l’année, enseignants, paiements en attente, examens ouverts, encaissé du jour.

Raccourcis en haut à droite (selon permissions) : Élèves, Inscriptions, Paiements, Examens, Bulletins.

6. Référentiel : année, classes, matières

6.1 Année académique

Menu : Référentiel → Années académiques.

  1. Cliquez Nouvelle année.
  2. Renseignez le nom (ex. Année académique 2025-2026), dates de début / fin.
  3. Cochez Activer : cela désactive les autres années.
  4. Enregistrer.

À la création d’une nouvelle année, vous pouvez réutiliser depuis une année existante : structures de frais, règles de notation, coefficients, sessions d’examens (brouillons). Les classes / matières / enseignants ne sont pas recopiés — ils existent déjà.

6.2 Classes

Menu : Référentiel → Classes → Nouvelle classe.

  • Nom : ex. 6ème A
  • Section : A, B, C… (listes éditables dans Paramétrage)
  • Laisser Actif coché

6.3 Matières

Menu : Référentiel → Matières → Nouvelle matière.

  • Nom : Mathématiques, Français…
  • Code : MATH, FR…
Données démo typiques : année 2025-2026 ; classes 6ème A, 5ème A, 3ème Exp. ; matières MATH, FR, ANG, SVT.

7. Enseignants

Menu : Scolarité → Enseignants → Nouvel enseignant.

Saisissez nom, téléphone, e-mail. Ce fichier est le référentiel pédagogique ; ce n’est pas automatiquement un compte de connexion (les comptes se créent dans Utilisateurs).

8. Élèves (profil permanent + photo)

Menu : Scolarité → Élèves.

8.1 Créer un élève

  1. Cliquez Nouvel élève.
  2. Student ID : laissez vide pour génération auto SCH-AAAA-0001, ou saisissez un code.
  3. Prénom, nom (obligatoires pour un profil utilisable).
  4. Genre, date de naissance, parent / tuteur, téléphone, e-mail (recommandés).
  5. Photo : Choisir et cadrer la photo — recadrez le visage (zoom / déplacement) puis validez.
  6. Enregistrer.

La colonne Profil affiche un pourcentage (ID, nom, genre, naissance, parent, téléphone, e-mail, photo). Vous pouvez inscrire même si le pourcentage n’est pas 100 %.

8.2 Compléter plus tard

Ouvrez l’élève → Gérer : ajoutez photo, téléphone parent, etc. L’historique (inscriptions, ledger, paiements, notes) reste sur la fiche.

Sans photo, la carte ID affiche une silhouette. Pour un test d’impression « réel », uploadez au moins une photo.

9. Inscriptions (chaque année)

Menu : Scolarité → Inscriptions → Nouvelle inscription.

  1. Recherchez l’élève (ID ou nom) — ne recréez pas un second profil.
  2. Choisissez l’année académique, la classe, la section.
  3. Statut : en général Inscrit.
  4. Enregistrer.

L’inscription peut déclencher l’imputation des frais (si une structure de frais existe pour cette classe / année) et une notification (souvent « ignorée » sans SMS).

Statuts possibles : Inscrit, Transféré, Diplômé, Inactif (listes modifiables).

10. Frais de scolarité et soldes

10.1 Structures de frais

Menu : Finances scolaires → Structures de frais.

  1. Nouvelle structure : nom (ex. Scolarité), année, classe, montant (ex. 75 000), devise XOF, actif.
  2. Une structure par classe / année est le cas le plus simple.

Exemple démo : 6ème A = 75 000 · 5ème A = 80 000 · 3ème = 90 000 XOF.

10.2 Soldes scolarité

Menu : Finances scolaires → Soldes scolarité (sous Paiements).

Cartes : À jour / Partiel / Impayé + reste à recouvrer.

Bouton Imputer les frais : crée les écritures manquantes pour l’année / classe filtrées (utile si vous avez créé les frais après les inscriptions).

Puis Nouveau paiement pour encaisser.

11. Paiements et reçus

Menu : Finances scolaires → Paiements → Nouveau paiement.

11.1 Méthodes

MéthodeEffetJustificatif
Espèces à l’écoleValidé tout de suite + reçuNon
Carte bancaireValidé tout de suite + reçuNon
Versement banqueEn attente jusqu’à vérificationOui (bordereau) + n° de référence
Mobile MoneyEn attenteOui + ID transaction
ChèqueEn attenteOui + n° de chèque

11.2 Test A — paiement à l’école (le plus simple)

  1. Nouveau paiement → élève inscrit → méthode Espèces à l’école.
  2. Montant (ex. 25 000), nom du payeur, enregistrer.
  3. Statut Validé. Ouvrez la fiche → Imprimer le reçu.
  4. Vérifiez le solde : l’élève passe en partiel ou à jour selon le montant.

11.3 Test B — paiement banque (circuit complet)

  1. Nouveau paiement → Versement banque : banque, n° de bordereau, photo / scan du reçu.
  2. Statut En attente.
  3. Ouvrez Gérer : consultez le justificatif → Valider (nom du caissier) ou Rejeter (motif).
  4. Après validation : reçu imprimable + solde mis à jour.
Le solde se calcule via le grand livre élève (débit = frais, crédit = paiements validés). Un paiement rejeté ne diminue pas le dû.

12. Cartes d’identité élèves

Menu : Scolarité → Cartes ID.

  1. Générer des cartes : année, éventuellement classe / section / genre / statut, code lot (ex. Promo-2026-A).
  2. Les cartes déjà générées pour le même élève / année ne sont en général pas recréées.
  3. Filtrez le lot, cliquez Imprimer le lot (ou Imprimer sur une ligne).
  4. Aperçu : 12 cartes par feuille A4 (grille 3 × 4). Dans la boîte d’impression, activez Graphiques d’arrière-plan pour garder le violet / vert.

Chaque carte : nom de l’école, photo ronde, classe, année, Student ID, téléphone, QR, mention de perte.

Le QR est imprimé ; le code-barres n’est pas encore dessiné (donnée stockée seulement). Impression via le navigateur (Imprimer / PDF).

13. Examens et notes

Menu : Examens & résultats → Examens.

  1. Nouvel examen : titre (ex. Devoir 1 — Trimestre 1), année, classe, matière, date, coefficient de l’épreuve, statut Ouvert.
  2. Ouvrez Gérer : saisissez une note par élève inscrit (sur la base du barème, souvent /20).
  3. Validez / enregistrez les notes. Passez l’examen en Clôturé quand la saisie est terminée.

Statuts : Brouillon → Ouvert (saisie) → Clôturé.

Un enseignant peut saisir les notes ; le directeur aussi.

14. Notation (barèmes, coefficients, règles)

Menu : Examens & résultats → Notation. Trois onglets :

OngletRôle
Systèmes & barèmesÉchelle (ex. /20) et mentions (Très bien, Assez bien, Ajourné…) avec notes min/max
CoefficientsPoids de chaque matière pour une année / classe
Règles de calculMoyenne de passage, moyenne de promotion, max de matières échouées, méthode de moyenne

Créez au moins un système actif avec quelques tranches (ex. 16–20 = TB, 10–11,99 = Passable, < 10 = Ajourné) avant d’imprimer des bulletins parlants.

Le « classement » actuel concerne le mode de calcul de moyenne, pas encore l’affichage du rang de classe (1er, 2e…) sur le bulletin.

15. Publication des résultats

Menu : Examens & résultats → Publication.

Onglet Règles : créez une règle, par exemple :

  • Frais soldés (oui / non)
  • Notes validées (oui / non)
  • Approbation directeur (oui / non)

Puis onglet Publications :

  1. Nouvelle publication : titre, année, classe (ou toutes), règle.
  2. Le système calcule les élèves éligibles vs non (frais, notes…).
  3. Si la règle l’exige : Gérer → approuver (nom du directeur).
  4. Publier. Statuts : Brouillon → En approbation → Publié (ou Rejeté).
Si la règle exige « frais payés » et que le solde n’est pas à jour, l’élève reste non éligible — c’est voulu. Payez / validez d’abord, ou assouplissez la règle pour le test.

16. Bulletins et relevés

Menu : Examens & résultats → Bulletins & relevés.

  1. Filtrez année et classe.
  2. Par élève : Bulletin ou Relevé (ouvre l’aperçu impression).
  3. Feuille de notes (filtre) : tableau de classe.
  4. Imprimez ou « Enregistrer au format PDF » depuis le navigateur.

La moyenne et la mention viennent du moteur de notation + notes saisies.

17. Recherche, langues, audit, utilisateurs

17.1 Recherche globale

Barre en haut : ID élève, nom, parent, téléphone, e-mail, classe. Cliquez un résultat pour ouvrir la fiche.

17.2 Langues

Menu : Administration → Langues. Le directeur peut activer / désactiver des langues. Un sélecteur peut exister dans l’en-tête. L’interface métier reste principalement en français dans cette bêta.

17.3 Audit

Menu : Administration → Audit. Journal des actions sensibles (élèves, inscriptions, paiements, notes, cartes…).

17.4 Utilisateurs et configuration

Menu Système → Utilisateurs : créez un compte (e-mail, mot de passe) et attribuez le rôle directeur, enseignant ou caissier.

Configuration : nom de l’établissement (affiché sur cartes / bulletins), logo si disponible.

18. Notifications (SMS / e-mail)

Menu : Administration → Notifications.

  • Journal : inscriptions, paiements, résultats, bulletins, annonces — canaux SMS / e-mail / système. Statut souvent Ignoré sans passerelle.
  • Annonce rapide : un message vers un téléphone ou un e-mail (pas un envoi de masse classe).
  • Paramètres : activer les canaux, Twilio ou webhook SMS, e-mail expéditeur — à laisser vide en bêta si non fourni.
Pour le test bêta, vérifiez surtout que le journal enregistre l’événement. L’absence de SMS n’est pas un échec.

19. Nouvelle année académique

  1. Créez la nouvelle année, cochez Activer.
  2. Choisissez « Réutiliser depuis… » et les cases Frais / Notation / Coefficients / Examens brouillons.
  3. Inscrivez les élèves existants dans leurs classes (nouvelle inscription, même profil).
  4. Imputez les frais, générez les cartes de la nouvelle année.

L’historique des années précédentes reste consultable sur la fiche élève.
